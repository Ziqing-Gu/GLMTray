# GLM 托盘助手 1.0.5 · 安装与使用

## macOS 13 或更新版本 · Apple 芯片与 Intel

1. 在总 ZIP 的 `Mac` 文件夹中双击 `GLMTray-1.0.5-macOS-Universal.pkg`，按安装器提示操作。两个架构共用这一个文件。安装位置为 `/Applications/GLM Tray.app`。更新前，从菜单栏退出正在运行的助手。
2. 从「应用程序」打开 **GLM Tray**。第一次请选择你平时使用的 **Genelec GLM 应用**。以后如果移动了原版 GLM，可在菜单栏重新选择。助手只在你选择「打开 GLM」时主动启动原版软件。
3. 从屏幕顶部的音箱图标选择「隐藏 GLM」或「显示 GLM」。自动隐藏默认开启。识别到已运行或新启动的 GLM 约十秒后，助手会在你切到其他应用时隐藏它。如果正在查看 GLM 的设置或校准界面，可以继续操作。手动显示后可以持续查看，直到你再次隐藏或重启 GLM。
4. 在菜单中勾选「登录时打开助手」。macOS 可能要求你在「系统设置 → 通用 → 登录项」中确认。也可在「登录时打开」手动添加已安装的 GLM Tray。登录后助手等待原版 GLM 正常启动。
5. 退出助手会恢复它隐藏的 GLM 窗口。助手只在菜单栏显示图标。原版 GLM 运行时会保留自己的程序坞图标。原有 MIDI 映射、音量与静音均由 Genelec GLM 处理。

**首次试用与安全。** 这个 PKG 未使用 Developer ID Installer 签名，App 采用本地签名（ad hoc），尚未通过 Apple 公证。通过网络取得的安装包可能会被 Gatekeeper 拦截。请核对来源并遵循自己或单位的 Mac 安全策略。[Apple 关于安全打开应用的说明](https://support.apple.com/zh-cn/102445)

**带硬件试用。** 保持原有监听音量，先确认控制器在 GLM 显示时能工作，再隐藏 GLM，试一次静音并恢复，然后重新显示 GLM。若 Cubase 或 Nuendo 与 GLM 争用设备，先启动原版 GLM，再打开宿主。卸载时先取消助手的登录项并退出助手，然后将「应用程序」中的 GLM Tray 移到废纸篓。

## Windows 10/11 x64

运行 `GLMTray-1.0.5-Windows-x64-Setup.exe`。本安装包未签名，为当前 Windows 账户安装。首次安装默认使用当前用户的程序目录，可在“选择目标位置”页浏览到自己的软件目录。请选择当前账户可以写入的专用文件夹。Genelec GLM 5 和监听硬件需要另行安装和配置。

**从旧版升级。** 如果用安装包装过助手，向导会默认选中之前的安装位置。保留目录会原位更新。选择其他目录后，安装器先校验新版、继承原有登录启动设置和适用的快捷方式，再调用旧助手自己的卸载程序。正在运行的已安装助手会短暂退出，完成后自动恢复。原版 GLM 可以一直开着。便携副本可在任意可写目录使用，请在升级前自行退出该副本。

**常用入口。** 更新后可继续使用原来的开始菜单条目及桌面或桌面一级子文件夹（例如“音乐制作”）中的助手快捷方式。迁移目录时，安装器更新已有链接的目标，保留名称、位置和启动参数。不会补建已删除的桌面图标。

**设置和数据。** 助手使用同目录的 `GLMTray.ini`。迁移时会把原设置复制到新目录；目标已有 INI 时保留目标文件。旧目录中的自建文件、INI 和日志会保留。需要手动指定 GLM 时，在 `[GLMTray]` 小节设置 `GLMPath=实际路径`，支持绝对路径或相对于助手的位置。含中文的 INI 请使用带 BOM 的 UTF-16 LE。需要诊断日志时，可加入 `Diagnostics=1` 并重启助手。

**托盘与监听。** GLM 主窗口出现约十秒后会隐藏。双击绿色监听音箱图标恢复主窗口，图标可能位于通知区域的折叠菜单。设置或错误对话框需要先处理。右键可切换登录启动；登录任务只启动助手。原版 GLM 的登录启动和 MIDI 映射请在原有设置中维护。如果 GLM 在 Cubase 或 Nuendo 已启动时提示设备冲突，先启动 GLM 再打开宿主。

**卸载。** 在 Windows“设置 → 应用 → 已安装的应用”中卸载 GLM Tray。助手的安装文件及属于此副本的登录任务会移除。便携用户应先关闭此副本的登录启动，再退出助手。
