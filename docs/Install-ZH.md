# GLM 托盘助手 1.0.2 · Windows x64

运行 `GLMTray-1.0.2-Windows-x64-Setup.exe`，选择助手的安装目录。安装仅针对当前 Windows 用户。安装器包含助手、这两份说明及许可证。Genelec GLM 5 和监听设备需要另行安装、配置。

首次使用时，先退出此前运行的托盘助手，再启动安装目录中的 `GLMTray.exe`。要替换旧版的登录启动项，可以先在旧助手托盘菜单取消「登录 Windows 后启动助手」，再在新助手中勾选同名选项。安装器最后一页可选择启动助手。助手和 GLM 各自的登录启动项独立，需要 GLM 登录后自动运行时，请保留原来的 GLM 启动设置。

GLM 启动完成约十秒后会自动收进托盘。双击右下角绿色 G 图标恢复主窗口；图标可能在 ∧ 折叠区内。点击 GLM 的最小化按钮可再次隐藏。退出助手会恢复 GLM 窗口。若 GLM 弹出设置或错误窗口，请先处理提示。本机使用 Cubase 或 Nuendo 时，先启动 GLM，再打开宿主。退出 GLM 本身会结束它对外部 MIDI 控制器的响应。

便携使用：将安装目录里的 GLMTray.exe 复制到另一个可写文件夹即可运行。助手通过 GLM 安装记录和 Windows 的程序目录识别 GLM。需要指定其他安装位置时，在助手旁建立 GLMTray.ini（路径含中文时保存为 UTF-16 LE，带 BOM），写入 [GLMTray] 小节和 GLMPath=实际路径。允许填写指向 GLMv5.exe 的绝对路径，或相对于助手的路径。移动助手后，重新启用托盘菜单的登录启动项以更新路径。最小化偏好保存在同目录的 INI 中；在该小节加入 Diagnostics=1 并重新启动助手，可在同目录生成 GLMTray.log。

卸载时先退出这一版本的托盘助手，再到 Windows「设置 → 应用 → 已安装的应用」选择 GLM Tray 1.0.2。只复制了 EXE 的便携用法没有卸载登记；请先取消该副本的登录启动，再退出助手。

本程序是独立的窗口管理工具，与 Genelec 官方无关。第一方代码及文档按随附的 Qing Audio 非商业源码共享许可证 1.0 提供。
